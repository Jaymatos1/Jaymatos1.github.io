## ✨ About the Mod & Project Goal

In the vast and sometimes volatile world of Minecraft servers, losing progress can be devastating. Auto World Backup solves this by providing a seamless, scheduled, and reliable method for backing up critical world data without requiring constant server oversight.

This website serves two purposes:
1.  **Promotion:** Showcasing the mod's advanced features to potential users.
2.  **Support:** Providing a stable platform for donations to fund continued development and compatibility updates.

## 🚀 Key Features of Auto World Backup

*   ✅ **Automated Scheduling:** Set precise backup intervals (e.g., hourly, daily) that run autonomously in the background.
*   🛡️ **Comprehensive Data Safety:** Backs up not just chunks, but also critical metadata, ensuring no loss of vital player progress or world structures.
*   ⚙️ **Ease of Use:** Simple setup process designed for both technical and non-technical server admins.
*   💻 **Cross-Platform Compatibility:** Designed to work seamlessly with the latest Minecraft versions running on major mod loaders (Fabric & Forge).

## 💻 Project Documentation (For Developers)

This repository hosts the static promotional website. It is built using modern web standards, ensuring maximum responsiveness and accessibility.

### Technologies Used
*   HTML5 (Semantic Structure)
*   CSS3 (SASS/SCSS methodology utilized for variables and nesting)
*   JavaScript (Vanilla JS for interactivity)

### Local Setup Guide
To run this website locally:
1.  **Clone the repository:**
    ```bash
    git clone https://github.com/YOUR-USERNAME/auto-world-backup.git
    cd auto-world-backup
    ```
2.  **Serve the files:** Since this is a static site, you can use any simple web server (like `live-server` or Python's built-in HTTP server):
    ```bash
    # Using VS Code Live Server extension: Right click -> Open with Live Server
    python -m http.server 8000
    ```
3.  The site will now be live at `http://localhost:8000/`
